# Linux Server Management

A Linux server administration toolkit created as a DevOps and Git workflow project.

## Purpose

The purpose of this project is to demonstrate Linux server administration tasks together with a professional Git and GitHub development workflow.

The project includes:

* Linux administration scripts
* system monitoring tools
* configuration examples
* installation documentation
* troubleshooting documentation
* Git branching and Pull Request workflow
* code review
* merge conflict resolution
* Git recovery procedures

## Project Structure

```text
scripts/    Linux administration scripts
config/     Project configuration
docs/       Project documentation
tests/      Script validation tools
.github/    GitHub workflow files
```

## Branching Strategy

The `main` branch contains only stable versions of the project.

New functionality is developed in separate branches such as:

* `feature/...`
* `docs/...`
* `fix/...`

Changes are merged into `main` through Pull Requests after testing and review.
